# NestJS 动态多租户数据库连接实现文档

## 1. 概述

本项目实现了一套完整的**多租户数据库连接管理方案**，允许单个 NestJS 应用根据请求上下文（例如请求头中的租户 ID）动态切换数据库连接。同时提供了：

- **连接池与超时自动断联**  
- **空闲连接自动回收**  
- **TCP Keep-Alive 与自动续期**  
- **数据库配置缓存**（减少重复查询）  
- **接口级别的无感切换**

适用于 SaaS 多租户、分库分表、微服务数据隔离等场景。

---

## 2. 技术栈

| 模块               | 技术选型                           |
| ------------------ | ---------------------------------- |
| 框架               | NestJS 11                          |
| ORM                | TypeORM 1.0 +  typeorm-extension   |
| 数据库驱动         | mysql2                             |
| 连接池管理         | 内置 + `extra` 底层参数            |
| 缓存（可选）       | Redis / 内存 Map（可替换）         |
| 配置管理           | js-yaml + 环境变量                 |
| 事件系统           | @nestjs/event-emitter（连接生命周期事件） |

> 注：本实现未强制依赖 Redis，可使用内存缓存快速验证；生产环境建议使用 Redis。

---

## 3. 核心架构

```text
HTTP Request (Header: X-Tenant-Id)
        │
        ▼
┌───────────────────────────────────┐
│   ContextMiddleware               │
│   - 提取租户ID                     │
│   - 绑定到请求上下文（AsyncLocalStorage）│
└───────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│   DbService                   │
│   - 从缓存/配置中心获取租户DB配置   │
│   - 配置内容: host, port, user... │
└───────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│   DynamicConnectionService        │
│   - 懒加载创建 DataSource           │
│   - 空闲连接定时清理                 │
│   - 连接测试与自动续期               │
└───────────────────────────────────┘
        │
        ▼
┌───────────────────────────────────┐
│   DynamicServiceModule            │
│   - 使用当前租户的 DataSource        │
│   - 执行数据库操作                   │
└───────────────────────────────────┘
```
## 4. 操作

创建 base、db1、db2 数据库并执行 db 下 db.sql，
ContextMiddleware内支持手动指定数据库

## 5. 总结

本方案通过 **请求级 DataSource 懒加载 + 连接池参数调优 + 空闲回收 + 缓存加速**，完美实现了：

✅ 接口级别动态连接数据库  
✅ 支持缓存降低配置查询开销  
✅ 超时自动断联（空闲超时、连接超时）  
✅ 连接自动续期（Keep‑Alive + 定期探活）  

代码已集成到当前项目中，可直接使用。
